# Ultra-Processed Foods and the BMI-Poverty Gap

This repository contains the R code used for the paper “Did the Rise of
Ultra-Processed Foods Reshape the BMI-Poverty Gap?”

## Contents

- `UPF_BMI_Analysis.R`: Data cleaning, OLS estimation, generalized random
  forest estimation, and figure creation.

## Data

The analysis uses National Health Interview Survey data from 1976, 1982,
and 1990. The data are not included in this repository. Researchers must
obtain the relevant files from the original data provider.

## Required packages

- tidyverse
- grf
- stargazer
- ggplot2
